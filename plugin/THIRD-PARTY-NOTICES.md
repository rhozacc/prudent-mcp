# Third-party notices

`bun run build:mcpb` bundles this server into a single `index.mjs` and packs it as a
`.mcpb`, statically linking the two runtime dependencies below. Both are MIT, which
requires their copyright and permission notices to travel with the redistributed
copy — so they are reproduced here, and this file is packed into the bundle.

Nothing else is redistributed. Everything under `devDependencies` is build-time only
and never reaches a shipped artifact.
